# Gather

A responsive budgeting and savings dashboard prototype built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Demo behavior

- Create savings goals and automatic savings reminders.
- Preview a 5% withdrawal fee and simulated net payout.
- Try simulated transfers and withdrawals; balances and activity are stored in browser local storage.

This prototype does not connect to a bank or move money. Real bank connections and transfers require a secure provider integration, backend services, user authorization, and applicable compliance review.
